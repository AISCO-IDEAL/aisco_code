Welcome to the WP7 GUI

This interface is the front-end shell for launching and monitoring local WP4 optimization runs. Use the sidebar to switch between pages without restarting the app.
Quick Start

Optimization Workspace

Start a run, choose an assembly ID, track progress, and inspect artifacts. This page combines run control, GIF previews, and the interactive 3D mesh viewer.

Solar Viewer

Focused page for solar-loss rendering GIF output from the latest run. Useful when you only want to monitor panel placement rendering.

Assembly Selection

Slider-driven assembly controls from WP2 GUI helpers. It writes values to parameters.yaml and shows the latest generated assembly.ply in real time.

Typical Workflow

  1. Open Optimization Workspace and click RUN.
  2. Watch progress and visual outputs update automatically.
  3. Switch to Assembly Selection to adjust seat and wheel positions.
  4. Switch to Solar Viewer for focused solar rendering checks.
