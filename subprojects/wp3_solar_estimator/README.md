# Solar Estimator


## Structure:
**helpers (folder):** contains small skripts that occainsionally might be useful, eg for generate a specific stl object or reefine a mesh. Also functions to visualize things belong here.

**main.ipynb:** a notebook to locally run the code an tes & visualize its behaviour.

**read_mesh.py.** This file contains funcitons that derive charecteistics directly from the mesh, eg angles.

**sun.py:** this file contains functions, to get the sun positon and the direction of the rays..

**run_race.ipynb:** a skript to do the calculations over multiple points in time and changed positions. "simulate a raceday"

## General remarks
